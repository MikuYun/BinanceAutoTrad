## 第 1 步：装 Node.js

### 检查是否已经装了

打开终端（Windows 用 **PowerShell**，macOS 用「终端」），输入：

```bash
node -v
```

- 打印 `v22.5.0` 或更高的版本号 → **已经装好了，跳到第 2 步**。
- 打印 `v18.x` / `v20.x` → 版本太低，需要升级（本项目用了 Node 22.5 才有的内置数据库模块）。
- 提示「找不到命令」→ 还没装。

### 没装 / 版本太低

1. 打开 <https://nodejs.org/>
2. 下载 **LTS** 版本（当前是 22 或 24 系列）
3. 一路「下一步」安装完
4. **关掉终端重新打开**（重要，否则环境变量不生效）
5. 再跑一次 `node -v` 确认

> Windows 也可以用 winget：`winget install OpenJS.NodeJS.LTS`
> macOS 也可以用 Homebrew：`brew install node`

## 第 2 步：启动服务

进入项目目录，运行入口文件。

**Windows PowerShell：**

```powershell
cd B:\biance_trae
node server.js
```

**macOS / Linux：**

```bash
cd /你的路径/biance_trae
node server.js
```

**看到这样的输出就成功了：**

```
══════════════════════════════════════
  币安量化终端 · U 本位永续
══════════════════════════════════════
  数据目录：B:\biance_trae\data
  监听地址：127.0.0.1:8787
  部署前缀：（站点根路径）
  实盘下单：已关闭（安全闸，只读）
  [路由] 认证 已挂载
  [行情] 数据源：币安实时行情（fapi.binance.com）
```

首次启动会自动在 `data/` 目录下创建两个东西：

| 文件 | 作用 |
|---|---|
| `data/app.db` | SQLite 数据库，存账号、机器人、订单、事件 |
| `data/master.key` | API Key 的加密主密钥（自动生成，权限 0600） |

> ⚠️ **`data/master.key` 一定要备份。** 它丢了，之前存进数据库的 API Key 就永远解不开了。

**不需要 `npm install`** —— 本项目零第三方依赖。

> 这个终端窗口就是服务器本体，**关掉它服务就停了**。想让它一直跑，见
> [DEPLOY.md](../DEPLOY.md) 里的 systemd 章节。

## 第 3 步：注册账号

浏览器打开：

```
http://127.0.0.1:8787
```

第一次进来会看到登录页，点上面的 **「注册」** 标签页：

| 字段 | 填什么 |
|---|---|
| 用户名 | 自己起一个，3~32 位字母、数字或下划线（比如 `miku`） |
| 密码 | 至少 6 位（建议用你记不住的强密码，但记得住） |

点「注册并登录」。

> 这是**纯本地账号**，只存在你这台机器的 `data/app.db` 里，不会上传到任何地方，
> 也不需要邮箱、手机号。忘记密码只能手动改数据库（见 FAQ）。

登录成功后会跳到「概览」页，顶部导航有 4 项：**概览 / 机器人 / 账户 / API Key**。

## 第 4 步：设置模拟盘钱包余额

在正式开机器人之前，先给模拟盘放点钱。

1. 点顶部导航 **「账户」**
2. 右上角点 **「设置模拟余额」**
3. 输入金额（默认 100，最小 10 USDT）
4. 「处理方式」保持默认的 **「重置钱包，并清空所有机器人的持仓」**
5. 点「保存」

关于这个钱包，有三件事要理解清楚：

- 它是**账户级**的，相当于币安全仓账户里的钱包余额，**所有模拟机器人共用这一个钱包**。
- 机器人开仓时从钱包里**占用**保证金，平仓后把盈亏和手续费**退回**钱包。
- 每个机器人自己还有一层限制：它最多只能动用「分配给这个机器人的资金」，
  这样开三个机器人也不会把同一笔钱重复下注三次。

> 钱包可以随时改，即使暂时没有机器人也能改。

## 第 5 步：建第一个机器人

点顶部导航 **「机器人」** → 右上角 **「+ 新建机器人」**。

弹窗里填四类东西：

### ① 机器人名称

随便起，比如 `BTC 稳健型`。只是给你自己看的标签。

### ② 交易标的

下拉框里是币安 U 本位永续合约里成交额靠前的标的，按成交额排序。
新手建议先选 **`BTCUSDT`** 或 **`ETHUSDT`**（流动性最好，滑点最小）。

### ③ 运行模式

| 选项 | 说明 |
|---|---|
| 模拟模式（不联网，本地模拟成交） | **新手选这个**。虚拟资金，本地撮合，零风险 |
| 实盘模式（调用币安真实接口） | 真钱。需要先在 API Key 页配好密钥 |

**第一次一定选模拟模式。**

### ④ 策略参数

表单会按参数定义自动生成，一共 13 项，第一次用**保持默认值**就好：

| 参数 | 默认值 |
|---|---|
| 交易方向 | 双向 |
| 分配给这个机器人的资金 | 100 USDT |
| 第一笔保证金占分配资金的比例 | 1% |
| 杠杆倍数 | 20 |
| 每加一次仓，金额是上一次的几倍 | 1.5 |
| 加仓间距 | 1% |
| 最多加仓几次 | 6 |
| 单方向最多投入多少钱 | 3 倍 |
| 全部加满时，最多能亏分配资金的百分之几 | 35% |
| 止盈方式 | 按均价 |
| 止盈幅度 | 0.5% |
| 止损幅度 | 5% |
| 每多久判断一次 | 5 分钟 |

表单下方会自动出现 **「计划预览」**，告诉你这套参数会算成什么样：

- 第一笔名义金额、保证金
- 每一笔的加仓触发价
- 每笔加仓后的均价、止盈价、止损价
- 多空两边分别的强平价
- 加满时最多亏多少钱

如果参数组合算不出可行计划（比如第一笔金额太小下不出去），这里会直接显示红色提示，
告诉你**要把哪个参数调到多少**。改参数的时候预览会实时刷新。

确认无误后点 **「创建」**。

## 第 6 步：启动并观察

回到机器人列表，找到刚建的机器人，点 **「启动」**。

启动后：

- 卡片上的状态变成 **运行中**
- 每 5 秒左右会执行一次决策
- 权益曲线开始有数据

进详情页（点机器人卡片）能看到实时情况。

## 第 7 步：看懂详情页

详情页从上到下分四块：

### ① 顶部 KPI

| 指标 | 含义 |
|---|---|
| 当前权益 | 分配资金 + 浮动盈亏 + 已实现盈亏 |
| 浮动盈亏 | 当前持仓还没平仓的盈亏 |
| 已实现盈亏 | 已经平仓落袋的盈亏 |
| 已建仓笔数 / 上限 | 现在是第几笔 / 最多几笔 |

### ② 计划预览 + 层位表

层位表会显示每一笔的：

| 列 | 含义 |
|---|---|
| 第几笔 | 1 就是现在建的那笔，2 是第一次加仓，以此类推 |
| 这笔名义 | 这一笔开多大（名义 = 保证金 × 杠杆） |
| 保证金 | 这一笔占用了多少钱 |
| 价格跌到这里才加(多) | **触发价 —— 价格真的走到这里才会加，不是现在就建好** |
| 加完后的多单均价 | 加了这一笔之后，持仓的平均成本变成多少 |
| 加完后的多单止盈 | 加完之后，反弹到这个价就止盈 |
| 加完后的多单止损 | 加完之后，跌到这个价就认亏 |

已经建过的笔会标 **「已建」** 徽章。双向模式会同时显示做多和做空两张表。

> **重点理解**：`最多加仓 6 次` 不代表现在开了 6 笔。
> 现在只有第 1 笔，后面 5 笔是「等价格走到触发价才会发生的动作」。

### ③ 事件日志 / 订单流水

- **事件日志**：机器人的每一步判断，比如「开多 第 1 笔：名义 20.00U，保证金 1.00U」、
  「平空：止盈（单层目标 81.29），盈亏 +8.05U」、「开仓被拒：账户可用余额不足……」。
  想知道机器人「为什么不动」，看这里。
- **订单流水**：每一笔实际成交的开平仓记录，含数量、价格、手续费。

### ④ 参数编辑

在详情页底部可以直接改参数，改的时候有实时预览，点「保存参数」生效。
**运行中的机器人不能改参数**，要先「停止」。

## 常见卡点

### 「参数不可行 / 最小可下单金额」

**原因**：`分配资金 × 第一笔占比 × 杠杆` 算出来的第一笔金额太小，低于交易所允许的最小下单量。

币安有两道门槛：

1. 单笔名义金额 **≥ 5 USDT**
2. 数量必须是 `stepSize` 的整数倍，且 **≥ `minQty`**

第二道更隐蔽。举例：某个合约价格 976，`minQty = 0.01`，
那最小的「0.01 个」就值 **9.76 USDT** —— 所以即使你名义写 6 USDT，也下不出去。

平台用的是：

```
最小可下单金额 = max(minNotional, ceil(minQty / stepSize) × stepSize × 现价)
```

**怎么办**：错误提示里会直接算出你需要把「分配资金」调到多少，或者把
「第一笔保证金占比」调到多少。按提示改就行。

### 「机器人一直不动」

**这通常是正常的。** 它在等价格走到计划的位置。

去详情页看「事件日志」。如果最后一条是很久以前的「建首层」或者什么都没写，
说明价格还没触发加仓，也没到止盈/止损。

如果日志里是「开仓被拒：账户可用余额不足」，那就是钱包被其他机器人占满了，
去账户页看看「可用余额」。

### 「行情显示不出来 / 价格不跳」

**原因**：你的网络访问不了币安的 `fapi.binance.com`（国内常见）。

平台会自动降级成本地模拟价格，并在页面上明确提示「降级」。这是设计成不崩溃的。

**怎么办**：给机器挂代理，或者把服务部署到能访问币安的服务器上（见 [DEPLOY.md](../DEPLOY.md)）。

### 「打不开 8787 端口」

**原因**：端口被别的程序占了。

**怎么办**：换个端口启动：

```powershell
# Windows PowerShell
$env:PORT=9000; node server.js
```

```bash
# macOS / Linux
PORT=9000 node server.js
```

然后访问 `http://127.0.0.1:9000`。

## 下一步

跑通模拟盘之后，按这个顺序继续：

1. **调参数** —— 读 [STRATEGY.md](STRATEGY.md)，理解 13 个参数分别影响什么，再试三档参考配置。
2. **至少跑两周模拟盘** —— 包括一段单边下跌行情，看看加仓被套是什么感觉。
3. **理解止盈止损** —— 详情页的「计划预览」能告诉你每一笔的止盈价和止损价是怎么来的。
4. **才考虑实盘** —— 读 [FAQ.md](FAQ.md) 的实盘章节，配 API Key（**只开合约交易权限，绝不开提现**），
   先用极小资金跑一周。
5. **想部署到服务器** —— 读 [DEPLOY.md](../DEPLOY.md)，用 systemd 常驻 + Nginx 反代 + HTTPS。

> 再重复一次：**合约交易有极高风险，会亏光本金。** 模拟盘赚多少都不代表实盘能赚。
